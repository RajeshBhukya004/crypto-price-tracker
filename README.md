# Crypto Price Tracker

## About the Project
Crypto Price Tracker is a web application that helps users view cryptocurrency price information through a simple dashboard.

## Features
- Cryptocurrency price tracking
- Dashboard interface
- Frontend built with HTML, CSS, and JavaScript
- Backend powered by Node.js

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js (if used in this project)

## How to Run the Project
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install backend dependencies by running `npm install` inside the `backend` folder.
4. Configure the required environment variables in a local `.env` file, if needed.
5. Start the backend using the command specified in `backend/package.json`.
6. Open the dashboard in your browser using the local address shown by the server.
